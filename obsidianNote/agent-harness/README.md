# Obsidian 个人知识库

> 用 [Obsidian](https://obsidian.md) 维护的个人知识库 —— 读书笔记、电子书摘录，以及日常学习与思考的积累。

## 简介

这里是我的个人知识库，全部以纯 Markdown 文件的形式存放，方便长期积累、双向链接和全文检索。工作、学习与阅读中的沉淀都汇总在这里，主要包含三类内容：

### 📚 读书笔记

书籍的摘录、批注与读后感。每本书一份笔记，记录核心观点、原文摘抄和自己的理解。

### 📖 电子书

电子书资料与阅读记录。整理书单、阅读进度，以及书中的重要章节与片段。

### 🧠 知识库

学习笔记与技术专题，把零散的输入整理成可复用的知识。例如：

- [Agent 驾驭工程之美](Agent-Harness.md)（系列笔记）

## 目录结构

```text
.
├── Agent-驾驭工程之美.md    # 笔记：Agent 驾驭工程系列
├── 2026-10-09-115028.png    # 笔记引用的图片（按时间命名）
└── .obsidian/               # Obsidian 配置（主题、插件等）
```

随着笔记积累，目录会不断调整，学科 / 书籍 / 专题会逐步分门别类。

## 使用方式

- 用 Obsidian 打开本仓库所在目录，即可直接作为 Vault 使用。
- 笔记为**标准 Markdown**，图片使用相对路径引用，因此在 GitHub 上也能正常浏览。
- 已启用核心插件：文件浏览器、全局搜索、双向链接、标签、日记、模板、大纲、图谱、书签等。

## 说明

- 本仓库为**个人知识库**，内容仅供学习与记录之用。
- 若需存放电子书原文，建议使用私有仓库或 Git LFS，避免大文件与版权问题。
